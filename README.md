# Comparative Genomic, Structural, and Phylogenetic Analysis of Bacterial ACC Deaminase (*acdS*) Across Contrasting Ecological Niches

**Author:** Anyela Paola Silvestre Romero (Universidad Antonio Nariño - UAN, Bogotá, Colombia)

## Repository Structure
- `scripts/`: Numbered bioinformatic retrieval, diagnostic filtering, and IQ-TREE v3.1.3 scripts.
- `data/`: Curated multi-FASTA dataset (`N = 45`) and `Supplementary_Material.xlsx`.
- `figures/`: Vector phylogenetic tree (`Figure1.svg`) annotated in iTOL v6.
- `manuscript/`: Editable manuscript (`Manuscript_Current_Microbiology_FINAL.docx`) and `Cover_Letter_Current_Microbiology.docx`.
